# PRD: 30초 역량 파악 포트폴리오 웹페이지

> 프리랜서 전환을 준비하는 퍼포먼스·그로스 마케터를 위한 개인 포트폴리오 사이트

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.0 |
| 작성일 | 2026-10-11 |
| 상태 | Draft (검토 대기) |
| 제품 형태 | 정적 웹사이트 (단일 랜딩 + 케이스 스터디 상세 페이지) |

---

## 1. 배경과 문제 정의

### 1.1 배경
- 프리랜서 마케터는 **이력서가 아닌 성과로 선택**받는다. 클라이언트(스타트업 대표, 마케팅 팀장, 에이전시 PM)와 플랫폼 담당자(크몽·숨고·위시켓·원티드 긱스 등)는 하루에 수십 개의 포트폴리오를 훑는다.
- 대부분의 마케터 포트폴리오는 PDF·노션 페이지로, **"무엇을 했는가(업무 나열)"** 중심이고 **"그래서 얼마나 벌어줬는가(결과)"** 가 묻혀 있다.

### 1.2 핵심 문제
| 문제 | 결과 |
|---|---|
| 첫 화면에서 전문 분야가 불분명 | 담당자가 "이 사람이 우리 문제를 풀 수 있나?"를 판단하지 못하고 이탈 |
| 성과 수치가 본문 깊숙이 묻힘 | 스크롤·클릭 전에 신뢰가 형성되지 않음 |
| 연락 경로가 복잡 | 관심이 생겨도 문의로 이어지지 않음 |
| 모바일 미대응 / 느린 로딩 | 메신저·메일로 링크를 받은 담당자가 모바일에서 바로 닫음 |

### 1.3 제품 목표 한 줄
> **"방문 30초 안에 _누구이고, 무엇을 잘하며, 얼마의 성과를 냈고, 어떻게 연락하는지_ 를 담당자가 말할 수 있게 한다."**

## 2. 목표와 성공 지표

### 2.1 목표 (Goals)
1. **30초 이해**: 첫 화면(Above the fold) + 1회 스크롤 안에 핵심 4요소(포지셔닝·대표 성과·전문 영역·CTA)를 모두 노출
2. **신뢰 확보**: 모든 성과 주장에 수치·기간·맥락·증빙을 붙인다
3. **전환**: 방문자를 "문의/미팅 예약"으로 연결
4. **프리랜서 상품화**: 제공 서비스와 협업 방식을 명확히 패키지화하여 "고용 가능한 사람"으로 보이게 한다

### 2.2 비목표 (Non-Goals)
- 블로그/CMS 기능, 회원가입, 다국어 완전 지원(v1은 한국어 + 영문 요약만)
- 결제·견적 자동화
- 화려한 3D/인터랙티브 연출 (로딩 속도와 가독성을 해치면 오히려 마이너스)

### 2.3 성공 지표 (KPI)
| 지표 | 목표치 | 측정 방법 |
|---|---|---|
| 5초 테스트 정답률 | ≥ 80% ("이 사람의 전문 분야는?" 질문) | 지인·타깃 5~10명 대상 UsabilityHub/수동 테스트 |
| 30초 테스트 정답률 | ≥ 70% (포지셔닝·대표 성과 1개·연락 방법 모두 답변) | 동일 |
| LCP (모바일) | ≤ 1.5s | Lighthouse / Vercel Speed Insights |
| Lighthouse 점수 | Performance·Accessibility·SEO 모두 ≥ 95 | Lighthouse CI |
| 첫 화면 스크롤 도달률(50%) | ≥ 60% | GA4 / Plausible scroll depth |
| 방문 → CTA 클릭률 | ≥ 5% | 이벤트 트래킹 |
| 월 문의 건수 | 런칭 3개월 내 월 3건 이상 | 폼 제출 + 캘린더 예약 |

## 3. 타깃 사용자 (페르소나)

| 페르소나 | 상황 | 30초 안에 알고 싶은 것 | 결정 기준 |
|---|---|---|---|
| **A. 스타트업 대표 / 마케팅 리드** | 광고비는 쓰는데 성과가 안 나와서 외부 전문가를 찾는 중 | "우리 업종·단계에서 성과 내본 적 있나?" | 유사 사례, ROAS/CAC 개선 수치 |
| **B. 에이전시·플랫폼 PM** | 프로젝트에 투입할 프리랜서를 빠르게 선별 | "어떤 채널·툴을 다루고, 바로 투입 가능한가?" | 스킬 스택, 가용 일정, 단가 범위 |
| **C. 채용 담당자 (정규직 가능성 포함)** | 계약직/정규직 전환 후보 탐색 | "경력 수준과 커뮤니케이션 능력은?" | 경력 요약, 추천사, 이력서 PDF |

> 설계 원칙: **페르소나 A 를 1순위**로 최적화한다. A를 설득하는 구성(비즈니스 임팩트 중심)은 B, C에게도 유효하다.

## 4. 30초 정보 설계 (핵심 UX 전략)

### 4.1 시간대별 정보 노출 목표

```
 0 ~ 5초   │ HERO        │ 나는 누구인가 + 무엇을 해결하는가 (포지셔닝 한 문장)
 5 ~ 15초  │ IMPACT BAR  │ 대표 성과 숫자 3~4개 (카운트업)
15 ~ 25초  │ CASE CARDS  │ 대표 케이스 3개: 문제 → 액션 → 결과 (카드 1장 = 1줄 요약)
25 ~ 30초  │ CTA         │ 고정 CTA: "30분 무료 진단 미팅 예약" / 이메일 복사
 30초 이후 │ DEEP DIVE   │ 서비스 패키지, 스킬 스택, 추천사, 상세 케이스, 이력서
```

### 4.2 카피 원칙
1. **"나" 보다 "고객의 결과"를 주어로**: ❌ "7년차 퍼포먼스 마케터입니다" → ✅ "광고비는 그대로, 매출은 2배. D2C 브랜드의 ROAS를 설계합니다"
2. **모든 성과는 `숫자 + 기간 + 맥락`**: ❌ "매출 크게 증가" → ✅ "6개월간 월 매출 1.2억 → 3.1억 (+158%), 광고비 동일"
3. **전문 영역은 3개 이하로 좁힌다**: 넓으면 신뢰가 떨어진다. 예: `퍼포먼스 광고 · CRM 리텐션 · GA4/데이터 분석`
4. **업계 용어 + 쉬운 말 병기**: "ROAS 420% (광고비 1원당 매출 4.2원)"
5. **NDA 대응**: 고객사명 비공개 시 "뷰티 D2C 브랜드 (연매출 50억 규모)" 형태로 업종·규모를 명시

## 5. 기능 요구사항

우선순위: **P0** = MVP 필수, **P1** = 런칭 직후, **P2** = 차기 개선

### 5.1 섹션 구성 (랜딩 페이지, 위→아래 순서)

#### F1. Hero 섹션 — P0
- **내용**
  - 이름 + 한 줄 포지셔닝 (헤드라인, 최대 30자)
  - 서브카피: 타깃 고객 + 해결 문제 (최대 60자)
  - 프로필 사진 (신뢰도 상승, WebP/AVIF, 우선 로딩)
  - 상태 배지: `🟢 2026년 11월부터 신규 프로젝트 가능`
  - Primary CTA: `무료 진단 미팅 예약`, Secondary CTA: `대표 사례 보기 ↓`
- **요구사항**
  - 모바일 기준 첫 화면(375×667)에 헤드라인·CTA가 모두 보여야 함
  - 텍스트는 이미지가 아닌 HTML 텍스트 (SEO·접근성·LCP)

#### F2. Impact Bar (핵심 성과 지표) — P0
- 3~4개의 대형 숫자 카드. 예:
  | 수치 | 라벨 |
  |---|---|
  | `₩42억+` | 누적 운영 광고비 |
  | `ROAS 420%` | 평균 달성 ROAS |
  | `-38%` | 평균 CAC 절감 |
  | `27개` | 협업 브랜드 |
- 뷰포트 진입 시 카운트업 애니메이션 (≤ 1.2초, `prefers-reduced-motion` 시 비활성)
- 각 수치에 툴팁/각주로 산출 기준 표기 (신뢰도)

#### F3. 대표 케이스 스터디 카드 — P0
- 3개 (최대 6개, 필터 없이 "가장 강한 3개"만 우선 노출)
- **카드 구조 (PAR 프레임)**
  ```
  [업종 태그] [채널 태그]
  제목: "광고비 동결 상태에서 월 매출 158% 성장"
  Problem : 신규 고객 CAC 상승으로 성장 정체
  Action  : 캠페인 구조 재설계 + 크리에이티브 테스트 체계화
  Result  : 6개월, 월 매출 1.2억 → 3.1억  ← 가장 강조
  [자세히 보기 →]
  ```
- 클릭 시 상세 페이지(F8)로 이동

#### F4. 서비스 패키지 (What I Offer) — P0
- 프리랜서로서 "무엇을 살 수 있는지" 명확화. 3개 이하 패키지
  | 패키지 | 내용 | 기간 | 가격 표기 |
  |---|---|---|---|
  | 광고 계정 진단 | 계정 감사 + 개선 리포트 | 1주 | `150만원~` 또는 "문의" |
  | 퍼포먼스 그로스 리테이너 | 월 운영 + 주간 리포트 | 월 단위 | `월 400만원~` |
  | GA4/트래킹 셋업 | 이벤트 설계 + 대시보드 | 2주 | 프로젝트 단위 |
- 가격 노출 여부는 설정값으로 토글 (`showPricing: true/false`)

#### F5. 스킬 & 툴 스택 — P0
- 카테고리별 아이콘 그리드: `광고(Meta, Google, Kakao, Naver)`, `분석(GA4, GTM, Amplitude, Looker Studio)`, `CRM(Braze, 채널톡)`, `자동화/AI(Zapier, ChatGPT/Claude 활용)`
- 숙련도는 막대그래프 대신 **"N년 / 운영 규모"** 텍스트로 (막대는 근거 없는 자기평가로 보임)
- 보유 자격증 배지 (Google Ads 인증, Meta Blueprint 등)

#### F6. 추천사 (Testimonials) — P1
- 2~4개, 이름·직함·회사(또는 업종) + 사진, 1~2문장
- LinkedIn 추천 링크 연결로 진위 확인 가능하게

#### F7. 협업 방식 (How I Work) — P1
- 4단계 프로세스: `진단 → 전략 제안 → 실행/테스트 → 리포트·개선`
- 커뮤니케이션 방식: 슬랙/노션 협업, 주간 리포트, 응답 시간(평일 24시간 내)

#### F8. 케이스 스터디 상세 페이지 — P0
- URL: `/work/[slug]`
- 구조: `TL;DR(3줄)` → `배경/과제` → `가설과 전략` → `실행` → `결과(차트 포함)` → `배운 점` → `다음 사례/CTA`
- 결과 차트: 기간별 매출·ROAS 추이 라인 차트 (데이터는 마스킹 가능)
- 증빙 이미지: 광고 관리자 캡처(민감정보 블러), 크리에이티브 예시
- 페이지 하단 고정 CTA

#### F9. 연락/CTA — P0
- **스티키 CTA 바** (모바일 하단 고정, 데스크톱 헤더 우측)
- 연락 채널: ① 캘린더 예약(Cal.com/Calendly 임베드) ② 이메일 원클릭 복사 ③ 카카오톡 오픈채팅 ④ LinkedIn
- 간단 문의 폼: 이름, 회사, 예산 범위(선택형), 문의 내용 → 이메일 + 슬랙/디스코드 웹훅 알림
- 스팸 방지: Cloudflare Turnstile 또는 honeypot

#### F10. 이력서 다운로드 — P1
- `이력서 PDF 다운로드` 버튼 (페르소나 C 대응), 다운로드 이벤트 트래킹

#### F11. 개인화 랜딩 (UTM 기반) — P2
- `?for=beauty` 처럼 쿼리 파라미터로 헤드라인·대표 케이스 순서를 업종별로 변경
- 지원·제안 시 업종 맞춤 링크를 보내 **"이 회사 문제에 맞춘 포트폴리오"** 인상 부여 (경쟁 지원자 대비 차별화 포인트)

#### F12. 영문 요약 페이지 — P2
- `/en` 단일 페이지 (해외 클라이언트/글로벌 플랫폼 대응)

## 6. 기술 방향

### 6.1 기술 선택 원칙
1. **속도가 곧 첫인상**: 정적 생성(SSG) + 최소 JS
2. **콘텐츠와 코드 분리**: 마케터 본인이 Markdown/JSON만 고쳐서 업데이트
3. **비용 0원 운영**: 무료 호스팅 티어로 충분

### 6.2 권장 스택

| 영역 | 선택 | 이유 | 대안 |
|---|---|---|---|
| 프레임워크 | **Astro 5** | 기본 Zero-JS 출력 → LCP 최상. 필요한 부분만 아일랜드로 인터랙션 | Next.js (App Router, SSG) |
| 스타일 | **Tailwind CSS v4** | 빠른 반응형 구현, 일관된 디자인 토큰 | vanilla CSS + CSS 변수 |
| 인터랙션 | 바닐라 TS + IntersectionObserver | 카운트업·스크롤 애니메이션에 라이브러리 불필요 | Motion One (경량) |
| 콘텐츠 | **Astro Content Collections** (Markdown/MDX + Zod 스키마) | 케이스 스터디를 `.mdx` 파일로 관리, 필드 누락 시 빌드 에러 | Notion API → 빌드 시 동기화 (P2) |
| 차트 | Chart.js 또는 경량 SVG 직접 렌더 | 케이스 상세에서만 lazy load | Recharts (React 사용 시) |
| 폼 | Formspree 또는 Cloudflare Pages Functions + Resend | 서버리스, 무료 티어 | Tally 임베드 |
| 예약 | Cal.com 임베드 (클릭 시 lazy load) | 무료, 구글 캘린더 연동 | Calendly |
| 분석 | **GA4** + (선택) Microsoft Clarity | 이벤트 트래킹 + 히트맵/세션 녹화로 30초 동선 검증 | Plausible (쿠키리스) |
| 호스팅 | **Vercel** 또는 Cloudflare Pages | Git push 자동 배포, 프리뷰 URL, 글로벌 CDN | Netlify |
| 도메인 | `이름.com` / `이름.kr` | 신뢰도. 명함·제안서에 노출 | — |

## 7. 디자인 가이드

- **톤**: 신뢰감 있는 미니멀 + 숫자를 주인공으로. 장식보다 여백
- **타이포그래피**: Pretendard. 성과 수치는 48~72px Bold, 본문 16~18px
- **컬러**: 중립 배경(화이트/차콜) + 포인트 컬러 1개 (CTA·성과 수치에만 사용 → 시선 유도)
- **시각 위계**: 페이지당 가장 큰 요소는 항상 "결과 숫자"
- **애니메이션**: 진입 페이드/카운트업 정도만. 300ms 이내, 모션 축소 설정 존중
- **레퍼런스 체크 포인트**: 첫 화면을 흐리게(blur) 봤을 때 헤드라인·숫자·CTA 3개 덩어리만 보여야 함

## 부록 B. 경쟁력을 높이는 차별화 포인트 요약

1. **결과 숫자를 주인공으로** — 업무 나열형 포트폴리오와 즉시 구분된다
2. **서비스 패키지화** — "사람"이 아닌 "구매 가능한 솔루션"으로 보인다
3. **업종별 개인화 링크(F11)** — 제안서마다 맞춤 포트폴리오를 보내는 효과
4. **본인 포트폴리오 자체가 마케팅 역량의 증거** — GA4 이벤트 설계·전환 퍼널·A/B 테스트를 자기 사이트에 적용하고, 그 결과를 케이스로 추가할 수 있다
5. **속도와 접근성** — 모바일에서 1초 내 로딩되는 것만으로도 디테일을 챙기는 사람이라는 신호를 준다
